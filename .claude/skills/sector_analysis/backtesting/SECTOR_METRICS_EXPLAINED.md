# Sector Analysis Metrics - Beginner's Guide

## The Big Picture: What Are We Trying to Find?

**Goal:** Find which sectors are attracting the most money RIGHT NOW.

Think of the stock market like a big party with different rooms (sectors). Money is like people at the party - they move from room to room. We want to **follow the crowd** and go where the most people (money) are going.

---

## The 4 Key Metrics Explained

### 1. **RS (20d)** - Relative Strength (20-day)

**What it measures:** How is this sector performing vs the S&P 500 over the last **20 trading days** (about 1 month)?

**In Simple Terms:** "Is this sector beating or losing to the overall market in the last month?"

**How to Read It:**
```
RS (20d) = +5.00%  → This sector beat SPY by 5% in the last month ✅ GOOD
RS (20d) = +0.50%  → This sector barely beat SPY (meh)
RS (20d) = -3.00%  → This sector lost to SPY by 3% in the last month ❌ BAD
```

**Why It Matters:**
- Shows **recent momentum** (what's happening RIGHT NOW)
- Positive RS (20d) means "hot money" is flowing INTO this sector
- Negative RS (20d) means money is flowing OUT

**Real Example (from your analysis):**
```
XLI (Industrials): RS (20d) = +5.70%
  → Industrials beat SPY by 5.70% in the last month
  → Money is flowing INTO industrials right now

XLC (Communications): RS (20d) = -5.50%
  → Communications lost to SPY by 5.50% in the last month
  → Money is leaving communications
```

---

### 2. **RS (60d)** - Relative Strength (60-day)

**What it measures:** How is this sector performing vs the S&P 500 over the last **60 trading days** (about 3 months)?

**In Simple Terms:** "Is this sector beating or losing to the overall market over the past 3 months?"

**How to Read It:**
```
RS (60d) = +25.00%  → Beat SPY by 25% over 3 months ✅ STRONG TREND
RS (60d) = +1.00%   → Slightly beat SPY (weak trend)
RS (60d) = -15.00%  → Lost to SPY by 15% over 3 months ❌ WEAK TREND
```

**Why It Matters:**
- Shows **established trend** (is this a new hot sector or has it been hot for a while?)
- Helps distinguish between:
  - **New leaders** (positive RS 20d, negative RS 60d) → Just starting to get strong
  - **Established leaders** (positive RS 20d AND 60d) → Been strong for a while
  - **Fading leaders** (negative RS 20d, positive RS 60d) → Losing steam

**Real Example:**
```
SMH (Semiconductors):
  RS (20d) = +4.85%
  RS (60d) = +49.44%
  → Semiconductors have been crushing it for 3 months AND still strong now
  → Established leader ✅

XLI (Industrials):
  RS (20d) = +5.70%  ← Positive (doing well recently)
  RS (60d) = -2.46%  ← Negative (was weak before)
  → Industrials are NEW leaders (early rotation signal)
  → Money just started flowing in 👀
```

---

### 3. **Momentum** - Combined 3-Month + 6-Month Returns

**What it measures:** How much has this sector gone UP or DOWN over the past 3 and 6 months combined?

**In Simple Terms:** "Is this sector on a rocket ship or sinking?"

**Formula:**
```
Momentum = (3-month return + 6-month return)

Example:
  3-month return: +15%
  6-month return: +25%
  Momentum = +15% + 25% = +40%
```

**How to Read It:**
```
Momentum = +100%+   → Rocket ship! 🚀 (doubled in 6 months)
Momentum = +30%     → Strong upward trend ✅
Momentum = 0%       → Going nowhere (flat)
Momentum = -20%     → Falling ❌
```

**Why It Matters:**
- Shows **overall trend strength**
- High momentum sectors tend to keep going up (trend continuation)
- Low/negative momentum sectors tend to keep going down

**Real Example:**
```
SMH (Semiconductors): Momentum = +136.80%
  → Up 136% over the past 6 months
  → Absolute beast mode! 🚀

XLC (Communications): Momentum = -14.16%
  → Down 14% over past 6 months
  → Avoid this sector ❌
```

---

### 4. **Score** - Composite Score (0-100)

**What it measures:** A **combined grade** that weighs all the metrics together.

**In Simple Terms:** "Overall, how strong is this sector? Give it a grade from 0 to 100."

**Formula (the math behind it):**
```
Score = weighted average of:
  - 25% RS (20d)      ← Recent strength
  - 25% RS (60d)      ← Trend strength  
  - 25% Momentum      ← Overall momentum
  - 25% Recent return ← Latest performance

All normalized to 0-100 scale
```

**How to Read It:**
```
Score = 80-100  → Top tier sector ✅ BUY
Score = 60-79   → Decent sector 👀 WATCH
Score = 40-59   → Mediocre sector (meh)
Score = 0-39    → Weak sector ❌ AVOID
```

**Why It Matters:**
- **One number** that combines everything
- Easy to rank sectors (highest score = best)
- Top 3 scores = sectors to buy

**Real Example (from your latest analysis):**
```
Rank 1: SMH - Score 88.5
  → RS (20d): +4.85%, RS (60d): +49.44%, Momentum: +136.80%
  → All metrics strong = High score ✅

Rank 13: XLC - Score 13.5
  → RS (20d): -5.50%, RS (60d): -16.14%, Momentum: -14.16%
  → All metrics weak = Low score ❌
```

## Common Questions

### **Q: Which metric is most important?**
A: **RS (20d)** - Shows where money is flowing RIGHT NOW.

But the **Score** combines everything, so use that to rank sectors.

### **Q: Can a sector have positive RS (20d) but negative RS (60d)?**
A: YES! This is called **early rotation**.
- Sector was weak before (negative RS 60d)
- But getting strong now (positive RS 20d)
- This is GOOD - you're catching it early!

### **Q: What if all metrics are positive?**
A: VERY STRONG sector (like SMH with score 88.5)
- Established leader
- Definite buy ✅

### **Q: Should I buy sectors with negative RS but positive momentum?**
A: NO. RS (20d) is more important.
- Negative RS (20d) = money is leaving NOW
- Positive momentum = was strong before, but fading
- Wait for RS (20d) to turn positive
